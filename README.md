# National Gallery Route Finder

A JavaFX application developed as part of a Data Structures and Algorithms assignment.

The application allows users to find routes between rooms in the National Gallery using graph-based pathfinding algorithms.

## Features

- Interactive gallery route planning
- Shortest path calculation using Dijkstra's algorithm
- Route finding using Depth-First Search (DFS)
- Support for waypoints
- Option to avoid selected rooms
- Route searching based on artworks and artists

## Technologies

- Java
- JavaFX
- Data Structures and Algorithms
- Graphs
- Dijkstra's Algorithm
- Depth-First Search (DFS)
